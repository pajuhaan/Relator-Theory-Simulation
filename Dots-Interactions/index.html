Notes
The cloud is seeded as an isotropic 2D Gaussian in (x,y), which implies a Rayleigh distribution in radius: r ~ Rayleigh(σ). For each particle, σ is set by the Relator rule σ = R / √π, where R is the particle's input parameter. The space is unbounded (no borders). Only the current camera viewport is rendered.
